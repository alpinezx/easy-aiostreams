# Changelog

Notable changes to easy-aiostreams, newest first. Control panel versions are in brackets. Each entry links to its pull request for the full detail.

## 24 November 2026

- Phone alerts: the watchdog now also loads each add-on's own address (MediaFlow, AIOMetadata, AIOManager), not only its health check, so a broken site or certificate for an add-on is caught too. Add-ons stopped on purpose are still skipped, and the Phone alerts page lists the new check. (Panel 1.65.5)
- **Fixed:** Control panel on phones: the Backups list on Backup & Restore starts open (each backup still folded), and Optional add-ons on Scripts keeps its summary on the right of the title, folded or open. On a wide screen, five sites' HTTPS certificates fit on one line across the This server card. (Panel 1.65.5)
- **Fixed:** Control panel: an action that runs past its time limit is now stopped for certain (forced after 10 seconds if it ignores the first request), Activity history and cleared logs are saved in a way a crash can't leave half-written, and the history can't trip over an entry being cleared at the same moment. Phone alerts' event bin and switches take the same lock as the watchdog, so a check and a click no longer overwrite each other. Change config checks every address in a WireGuard config, not just the first, and the Logs page hides the panel's unlock link. (Panel 1.65.4, [#224](https://github.com/alpinezx/easy-aiostreams/pull/224))
- **Fixed:** Scripts: tidying an older Caddyfile's indents rewrites the file in place, so Caddy sees the change without being recreated. Phone alerts with the VPN on count an unexpected error reaching AIOStreams through the VPN as a failed check instead of a pass. ([#224](https://github.com/alpinezx/easy-aiostreams/pull/224))
- **Fixed:** Control panel through a Cloudflare Tunnel: the panel now sees each visitor's own address, so the sign-in lockout and the activity log no longer treat everyone as one visitor. Sign-in counts each try before checking the password, so many tries sent at once can't get past the lockout, and actions, reboots and script updates wait while a panel update or a maintenance job is still running. A panel update that didn't build or didn't come up no longer reports success. (Panel 1.65.3, [#223](https://github.com/alpinezx/easy-aiostreams/pull/223))
- **Fixed:** Scripts with the VPN on: Start, Restart and Update AIOStreams report a failure when the tunnel wasn't confirmed, a restore says so when AIOStreams didn't start, and the VPN route watcher waits for the tunnel check instead of recreating AIOStreams alongside it. Phone alerts no longer put the ntfy topic on a command line, where the server's process list showed it, and Reconfigure's backup copy of the compose file keeps its owner-only permissions. ([#223](https://github.com/alpinezx/easy-aiostreams/pull/223))
